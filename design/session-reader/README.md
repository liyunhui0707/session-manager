# Session Manager 阅读器外观原型

直接用 Safari 或 Chrome 打开同目录的 `index.html`。无需安装、构建或启动服务器。
这是保留的设计基准，整体布局已迁入生产应用；此目录仍是独立原型，全部会话为虚构示例。
不读取个人聊天、不连接 CLI、不联网，不保存来源或设置。刷新可恢复默认。

## 设计方向

安静、精致的 macOS 桌面阅读器。左侧负责找会话，右侧负责读内容。
暖白与灰绿色构成浅色主题，深色主题沿用同一套布局和控件。
正文默认 16px、最大阅读宽度 720px；代码独立横向滚动，表格、引用、列表有统一样式。
诊断信息收进会话信息，不把文件大小、扫描进度、分段编号放在阅读主界面。
打开会话定位最新内容，回看时通过轻量按钮返回底部。

## 可点击的界面

| 入口 | 可以体验的内容 |
| --- | --- |
| 会话列表 | Codex / Claude / 全部筛选、日期分组、收藏筛选、会话切换 |
| 搜索对话 / ⌘K | 标题与正文搜索、结果摘要、无结果状态、Enter 打开第一项并高亮 |
| 正文右上角 | 收藏、当前会话查找、会话详情侧面板 |
| 阅读区 | 更早的消息、回到最新、Markdown 样式、复制代码/回复 |
| 左下角来源 | 连接/断开虚构来源、重新检查反馈 |
| 左下角设置 | 浅色/深色/系统主题、三档字号与宽度、跟随开关 |
| 右下角“预览其他状态” | 日常阅读、长会话、首次打开、加载、来源不可用、部分内容不可读、重命名、新消息、重置 |

“新消息到达”场景特意模拟正在回看历史时收到回复，保留历史位置，点击提示可到最新。
“跟随最新消息”开关展示设置状态；原型没有后台消息源，不代表实时同步引擎已完成。
Claude 的原生来源管理、多来源同时连接、完整中文界面均是设计目标展示，不能据此认定生产功能已实现。
复制功能受浏览器剪贴板权限影响；失败时会提示直接选择文字复制。

## 本次实际检查（2026-11-04）

通过 macOS 原生 UI 操作，在 Safari 中验证了：

- 会话切换、来源与收藏组合筛选；默认打开到最新。
- 搜索“最新”、Enter 打开、出现 1/2 匹配；Esc 关闭搜索。
- 浅色/深色设置和来源管理面板的实际视觉效果。
- 断开来源、空白状态、重新连接示例来源。
- 长历史及返回最新、重命名同步、新消息提示与跳转。
- 来源异常/重试、部分内容提示及详情、加载反馈及结束、重置演示。
- 响应式设计预览 900×600：列表与正文独立滚动，标题栏、底栏可用，设置弹窗在视口内滚动。

检查中修复了搜索回车重复激活、断开后残留查找栏、空白状态底栏被滚动事件覆盖、
以及延迟动画帧导致新消息按钮文案未及时出现的问题。Chrome 的首次阅读预览可见；
后续重载出现工具侧空白/截图滞后，完整交互复核改用 Safari，未把它记为 Chrome 全套通过。

尚未完成正式 VoiceOver/输入法、手机布局或浏览器兼容性矩阵；建议桌面视口至少 900×600。
这份原型以可点击的视觉评审为目的，使用预先编写的可信示例 HTML，不是接收任意 Markdown 的生产渲染器。

## 文件

- `index.html`：页面骨架、图标与弹窗。
- `prototype.css`：主题、排版、控件和响应式规则。
- `fixtures.js`：七段虚构对话。
- `prototype.js`：页面交互与状态演示。

生产 Electron 界面位于 `apps/desktop/index.html` 和 `reader.css`，使用可信 IPC、
主进程来源状态及安全 Markdown 渲染。这里的示例数据逻辑仅用于设计演示。
