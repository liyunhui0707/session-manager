开始使用

三步，回到你的对话。

  1. 01 / 下载

    选择适合 Mac 的安装包

    目前提供 M 系列芯片版本。从本页或 GitHub Releases 下载 DMG。

  2. 02 / 安装

    拖入“应用程序”

    打开磁盘映像，拖入 App，然后推出映像，从“应用程序”启动。

  3. 03 / 阅读

    自动找到本地 Codex

    首次尝试读取 ~/.codex。使用其他位置时，选择一次，后续自动恢复。

macOS 提示无法验证开发者，怎么办？+

当前发行包未使用 Apple Developer ID 签名或公证。确认从本仓库下载后，尝试打开，再在“系统设置 → 隐私与安全性”中按系统提示选择“仍要打开”。不需要购买开发者会员，也不要全局关闭安全保护。

如果提示已知恶意软件、文件损坏或没有允许打开的选项，请停止并反馈。查看 Apple 官方说明 ↗

如何更新？+

下载新版本，正常退出旧 App，再替换“应用程序”中的版本。阅读设置会保留，聊天源文件不变。当前采用手动更新，尚不提供应用内自动安装。

也可以阅读 Claude 的聊天吗？+

可以阅读已有的 Claude / Codex Markdown 导出库。当前的原生来源接入专注于 Codex，Claude 原生会话接入暂缓。

图片和特别长的对话有什么限制？+

支持仍存在的本地静态 PNG / JPEG，最大 8 MiB、2400 万像素；已删除的临时截图无法恢复。长会话首次打开和未缓存搜索需要扫描，格式或资源限制导致的不完整读取会明确提示。完整使用说明 ↗
