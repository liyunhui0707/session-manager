# Session Manager 0.11.0

## 多窗口阅读

- 使用 ⌘N、侧栏“＋”或“文件 → 新建窗口”打开独立阅读窗口。
- 右键会话，选择“在新窗口打开”。可将窗口放到不同 macOS 桌面，或单独全屏。
- 来源、会话、分页、阅读位置、搜索与取消任务按窗口独立管理；关闭一个窗口不影响其他窗口。
- 收藏、主题、字号与阅读宽度在同一应用的窗口间同步。

退出应用会关闭全部窗口。下次启动恢复来源，不恢复上次的多窗口布局。更多窗口会使用更多内存。

## 安装与更新

提供 Apple Silicon（arm64）DMG 和 ZIP，要求 macOS 12 或更新版本。当前不提供已验收的 Intel 二进制。

安装包使用 ad-hoc 签名，未使用 Developer ID，也未经过 Apple 公证。首次打开可能需要在 macOS“隐私与安全性”中确认。遇到“已损坏”提示应停止并反馈，不要关闭系统保护或移除下载安全标记。

更新方式：下载新版，正常退出旧版，再替换原位置的 App。阅读设置与收藏保留，聊天源文件不变。当前没有应用内自动下载安装更新。

## 验证范围

本轮已完成 700 项自动测试、164 项打包合成检查，以及原生新建窗口、全屏、窗口隔离和跨桌面拖放验收。测试使用虚构会话，聊天源文件保持不变。

本版未新增另一台 Mac 的浏览器下载与 Gatekeeper 验收；0.10.3 的跨机安装记录仅证明该版本的行为。最低系统版本声明不代表已逐个验证所有 macOS 版本。完整依赖审计仍报告已评估的构建工具中等级告警，详见 [依赖审计](dependency-audit.md)。
