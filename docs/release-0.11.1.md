# Session Manager 0.11.1

## 图片阅读修复

- 图片离开视野时释放预览像素，并保留随窗口宽度调整的占位，避免正文高度变化和滚动跳动。
- 点击“关闭预览”后，当前页面内滚动不会重新展开；点击“加载图片”可再次打开。切换会话、翻页或重新读取后按新页面加载。
- 取消离屏图片的过期加载结果，保留最多四张预览的资源上限，并按实际缩略图尺寸安排布局。

## 安装与更新

提供 Apple Silicon（arm64）DMG 和 ZIP，要求 macOS 12 或更新版本。Intel 暂不提供已验收的二进制。

安装包采用 ad-hoc 签名，未使用 Developer ID，也未经过 Apple 公证。首次打开可能需要在 macOS“隐私与安全性”中确认；遇到“已损坏”提示应停止并反馈，不要移除下载安全标记或关闭系统保护。

下载新版，正常退出旧 App，再替换原位置的 App。阅读设置与收藏保留，原始聊天文件不变。当前采用手动更新，不提供应用内自动下载安装。

## 验证范围

修复已通过 705 项自动测试和 181 项打包合成界面检查。旧版在同一滚动回归检查中复现失败，修复版通过反复滚动、关闭后滚动、手动重新加载和窄窗口检查；合成聊天文件保持不变。

本轮未新增另一台 Mac 的浏览器下载与 Gatekeeper 验收。最低系统版本声明不代表已逐个验证所有 macOS 版本。完整依赖审计中的既有构建工具中等级告警及范围见 [依赖审计](dependency-audit.md)。
