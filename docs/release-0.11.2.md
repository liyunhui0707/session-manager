# Session Manager 0.11.2

## 从最新消息向上阅读更稳定

- 修复图片首次加载时，下方已读正文被推移的问题。
- 图片卡片提前预留稳定的预览和状态区域，加载、失败和离屏释放不会再撑开或收缩正文。图片按比例完整显示，点击可查看大图。
- 保留“关闭预览”后的收起状态；当前页面内上下滚动不会自动展开，点击“加载图片”可再次打开。

## 安装与更新

提供 Apple Silicon（arm64）DMG 和 ZIP，要求 macOS 12 或更新版本。Intel 暂不提供已验收的二进制。

安装包采用 ad-hoc 签名，未使用 Developer ID，也未经过 Apple 公证。首次打开可能需要在 macOS“隐私与安全性”中确认；遇到“已损坏”提示应停止并反馈，不要移除下载安全标记或关闭系统保护。

下载新版，正常退出旧 App，再替换原位置的 App。阅读设置与收藏保留，原始聊天文件不变。当前采用手动更新，不提供应用内自动下载安装。

## 验证范围

修复已通过 706 项自动测试和 201 项打包合成界面检查。新增场景从会话底部以连续小步向上滚动：旧版首次加载图片时正文额外位移约 438 像素，修复候选为 0；合成聊天源文件保持不变。

修复候选已获真实触控板人工验收确认。本轮未新增另一台 Mac 的浏览器下载与 Gatekeeper 验收；最低系统版本声明不代表已逐个验证所有 macOS 版本。完整依赖审计中的既有构建工具中等级告警及范围见 [依赖审计](dependency-audit.md)。
