# 0.10.3 — macOS 安装修复

已完成另一台 Apple Silicon Mac 的浏览器下载安装与退出重开验收。此版本修复首次打开时的签名封装故障，阅读功能保持不变。

修复 0.10.2 应用签名封装不完整的问题。下载文件本身校验正确，
但 macOS 在首次打开时提示“已损坏”。本版本为完整 App 和内置辅助
程序生成 ad-hoc 签名，并在生成 DMG、ZIP 前强制验证签名。

Apple Silicon (ARM64), macOS 12 or later. Ad-hoc signed; no Developer ID
identity or Apple notarization. Installation and updates remain manual.
Minimum OS is a declared requirement, not a claim of testing every OS version.

## 安装与更新

下载本页的 Apple Silicon DMG，将 App 拖入“应用程序”。更新前正常退出旧版，再替换 App；阅读设置保留，聊天源文件不变。

本版本未使用 Developer ID 签名，也未经过 Apple 公证。首次打开可能被 macOS 阻止；确认来源后，可在“系统设置 → 隐私与安全性”中按“仍要打开”流程确认。详见[安装指南](https://github.com/liyunhui0707/session-manager/blob/main/docs/installation.md)。

本轮跨机首次打开验收使用 DMG；ZIP 内 App 已通过严格签名检查，未单独进行浏览器下载后的首次打开验收。Intel 与最低系统版本尚未完成交互验收。

若系统提示“已损坏”，请取消打开并反馈，不要移除下载隔离标记或
关闭系统安全保护。签名完整性通过不等于 Apple 公证或 Gatekeeper 验收通过。
