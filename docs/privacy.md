# 隐私与本地数据

AI Session Manager 的阅读功能在本机执行，不向项目维护者、OpenAI、Anthropic 或其他服务上传聊天正文。应用没有遥测、广告、账户登录或云同步功能。

## 读取什么

选择 Codex 根目录后，应用读取目录项、文件元数据、会话名称索引和有界的来源标记以生成列表。选择会话、检查已选会话的新消息或明确执行正文搜索时，读取相关会话正文。归档记录不进入普通浏览与搜索列表。

图片仅从授权的本地范围读取，远程图片不会自动加载。符号链接与受保护目录受到读取限制。

## 保存什么

来源路径、上次来源类型、收藏与外观设置保存在 Electron 的本机应用数据目录中。阅读与搜索缓存位于进程内存，不建立持久全文索引，也不写出解压后的会话副本。操作系统仍可能自行管理交换空间、崩溃日志等；这不是操作系统沙箱或取证级“零痕迹”承诺。

## 写入边界

打开、翻页、搜索、刷新 Codex 列表和查看图片不会修改原始会话。Markdown 库的显式“刷新导入”是独立的写操作，将导出文件写入所选库的 `codex/` 和 `claude-code/` 子目录。

## 网站与下载

产品网站不读取本机聊天，也不添加第三方分析脚本。托管网站和 GitHub 下载服务可能按各自政策记录 IP 地址等访问日志。点击下载时由浏览器访问 GitHub。

## 问题反馈

请勿在公开 Issue 中粘贴聊天、凭据或未脱敏的截图、路径。使用虚构复现内容。安全问题请先阅读 [安全政策](../SECURITY.md)。
