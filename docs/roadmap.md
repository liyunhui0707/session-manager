# Product direction

The current focus is a dependable, local Codex reader and a maintainable public Mac distribution.

## Current release

Prompts and final replies, unarchived conversation browsing, latest-first reading, directional paging, search continuation, favorites, themes, 14–26 px text, local image previews and saved source startup are available. Existing Markdown export libraries are supported.

## Distribution

The first public channel provides source, documentation, a product website and unsigned Apple Silicon downloads with manual updates. Developer ID signing, Apple notarization and verified in-app updates are the next distribution milestone. Intel binaries need architecture-specific build and packaged acceptance before being offered as tested downloads.

## Maintenance

Continue compatibility testing as Codex formats evolve. Priorities include large-file first-read cost, compressed random access, uncached search cost and longer-duration resource observations. Existing improvements do not eliminate full scans in every case or prove absence of all memory leaks.

Native Claude session integration is paused. Editing, AI summaries, cloud synchronization and accounts are outside the current product boundary.
