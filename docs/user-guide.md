# 使用指南

## 选择来源

首次启动尝试 `~/.codex`，后续恢复上次来源。左下角来源按钮可切换完整 Codex 根目录、单个 JSONL / Zstd 会话文件，或已有 Markdown 会话库。完整根目录可提供保存的会话名称；只选择 `sessions` 子目录可能缺少名称。

列表显示未归档的交互对话，隐藏可识别的审核、子代理和非交互任务。来源未知的记录保留，避免误隐藏；初始化后从未开始对话的小文件也会被过滤。数量不表示正在运行的进程，也不保证与不同 Codex 版本的内部列表完全相同。归档、恢复与重命名会自动同步。

Markdown 库应包含 `codex/` 或 `claude-code/` 子目录，其中放置导出的 `.md` 文件。阅读支持两类导出；不代表已接入 Claude 原生会话。

## 阅读

- 打开会话定位到最新消息。
- **较早消息**定位到上一部分末尾，**较新消息**定位到下一部分开头。
- **回到最初 / 回到最新**直达两端。
- 正在阅读历史内容时，新回复不会强制改变阅读位置；提示按钮可带你回到末尾。
- 助手回复默认展开，长提示词可折叠；展开与折叠不改变原文。
- 顶部工作目录来自会话的结构化信息，悬停可查看完整路径。

只展示用户提示词和可以确认的最终回复；工具调用、思考和中间进度不属于阅读视图。旧格式中无法确定是否为最终回复的内容会计入诊断，而不会被猜测为最终答案。

## 多窗口阅读

**⌘N** 或侧栏“＋”新建窗口，继承当前来源；右键会话选择“在新窗口打开”，直接阅读该会话。也可使用“文件 → 新建窗口”。每个窗口有独立的会话选择、阅读位置、分页、搜索和加载任务。切换来源仅影响当前窗口，最后选择的来源作为下次启动的默认来源。

窗口可通过 macOS 调度中心放到不同桌面，也可单独全屏。**⌘W** 关闭当前窗口，**⌘Q** 退出整个应用。收藏、主题、字号与阅读宽度在窗口间共享；重启应用恢复来源，不恢复窗口数量和各窗口的阅读位置。打开更多窗口会增加内存占用。

## 搜索与收藏

**⌘K** 搜索当前或全部未归档对话的完整可读正文；每页最多 200 条结果，下一页继续浏览。每条消息返回第一个匹配片段。**⌘F** 只查找当前显示的部分。搜索为不区分大小写的字面匹配，不使用 AI。

跨部分命中会定位到对应部分；跨长消息切分边界的匹配可能需要翻页才能读完，不能跨两页同时高亮。源文件更新会让旧结果续页失效，请重新搜索。取消或部分文件不可读取时，会明确提示搜索不完整。

侧栏星标筛选收藏，标题栏星标切换当前会话收藏。收藏只写入应用设置，不改聊天文件。

## 外观与图片

设置支持系统 / 浅色 / 深色主题、两种阅读宽度和 14、16、18、20、22、24、26 px 字号。**A− / A+** 或 **⌘− / ⌘+** 调整正文，**⌘0** 恢复 16 px。

受支持的本地静态 PNG / JPEG 图片会在进入视野时关联，最大 8 MiB、2400 万像素。受限路径可由你手动选择图片。点击缩略图放大，Escape 关闭。图片关联不写回聊天记录；被清除的临时截图不能恢复。内嵌编码、远程地址和一般 Markdown 图片不会自动下载。

滚动离开图片时会释放预览像素，并保留图片占位，避免正文随之跳动。点击“关闭预览”后，当前页面内滚动不会重新展开；点击“加载图片”可再次打开。切换会话、翻页或重新读取后，图片按新页面重新加载。

## 加载与诊断

首次打开或未缓存搜索需要扫描文件；大文件可能较慢。安全路径、格式与资源限制不能通过隐藏提示绕过。黄色提示说明部分记录未能完整读取，搜索也可能不完整；详情见右上角“会话信息”。不要把它理解为聊天源文件被删除。

“重新读取当前会话”刷新当前正文；“立即同步列表”刷新来源目录。Markdown 的“刷新导入”不同：它会显式生成或更新导出库文件。普通 Codex 阅读始终只读。
